# Знак «Лексикон ЦС»

Выбран владельцем 5 ноября 2026 года: «ЦС» в шрифте Monomakh Unicode.
Бордовый фон, светлый круг и чёрные буквы сохраняют родство с логотипом
«Уставных чтений». Буквы взяты из нашего проверенного церковнославянского шрифта;
в SVG сохранены контуры, а не зависимость от установленного шрифта.

`app-icon.svg` — выбранный векторный оригинал, `app-icon.png` — 1024×1024.
`store-icon-512.png` — отдельный экспорт для магазина: PNG, 512×512, 1:1,
23 290 байт (менее 1 МБ). Подготовлен из выбранного SVG без изменения знака.
`concepts.png` — сравнение трёх предложенных вариантов с образцами 48×48.
Иконки Android и iOS подготовлены во всех размерах, указанных в проектах.

Воспроизведение из корня проекта:

```sh
python -m venv /tmp/cs-icon-tools
/tmp/cs-icon-tools/bin/pip install fonttools pillow
/tmp/cs-icon-tools/bin/python tool/generate_icons.py cs
```

Зависимости нужны только инструменту. Шрифт и его лицензия находятся в
`assets/fonts/`; библиотеки генерации не входят в приложение.
