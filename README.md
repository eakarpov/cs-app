# ЦС Словарь

Сетевое приложение на Flutter для Android и iOS, идентификатор `info.typikon.cs`. Словарь — главный экран: поиск слова или словоформы, статьи отдельных источников, формы и окончания, смысловые связи и проверенные этимологические свидетельства.

Реализованы оба направления поиска, церковная панель ввода, различение переводов и упоминаний в объяснениях, таблицы с русскими подписями, ссылки между статьями и отправка замечаний. Избранное, последние 100 статей, тема, размер текста и настройки выделения сохраняются на устройстве. В коде добавлена «Энциклопедия»: азбуки (кириллица и глаголица), диакритика и знак тысячи. Справочные страницы включены в приложение; они войдут в следующую тестовую сборку. Статьи словаря загружаются по сети. Полной локальной базы, аккаунтов, читателя и курсов в этой версии нет.

## Запуск и проверки

Нужен Flutter с Dart 3.12.2. Для Android нужны Android SDK/JDK, для iOS — полный Xcode и настроенная подпись.

```sh
flutter pub get
flutter analyze
flutter test
dart run tool/check_live_dictionary.dart
flutter run \
  --dart-define=CS_API_BASE_URL=https://YOUR-STAGING/api/v2/cs/ \
  --dart-define=CS_INTERLEX_BASE_URL=https://YOUR-INTERLEX/api/public/cs/
```

URL должны заканчиваться `/`. По умолчанию указаны `https://www.typikon.info/api/v2/cs/` и `https://interslavic-lexicon.com/api/public/cs/`. Оба API и словарная публикация активированы 5 ноября 2026 года; существующий APK работает с ними без пересборки. Отчёт — [docs/api-deployment.md](docs/api-deployment.md). Серверные API-ключи в приложение не встраиваются.

```sh
flutter build apk --release \
  --dart-define=CS_API_BASE_URL=https://YOUR-STAGING/api/v2/cs/ \
  --dart-define=CS_INTERLEX_BASE_URL=https://YOUR-INTERLEX/api/public/cs/
flutter build ios --simulator --debug
```

Текущая Android release-конфигурация подписывает сборку отладочным ключом: APK предназначен для закрытой проверки. Перед магазином нужны собственная подпись и проверка на физических устройствах. Информация о выполненных проверках и остающихся условиях выпуска — в [docs/acceptance.md](docs/acceptance.md).

## Устройство

- `lib/features/dictionary/domain/` — модели пользовательского контракта и грамматические подсказки.
- `lib/features/dictionary/data/` — HTTP-репозиторий с тайм-аутами и независимой загрузкой interlex.
- `lib/features/dictionary/presentation/` — экраны и `ChangeNotifier` поиска с защитой от устаревших ответов.
- `lib/core/personal_store.dart` — локальное состояние с последовательной записью и защитой от перезаписи после ошибки чтения.
- `assets/fonts/` — проверенные Monomakh Unicode и Old Standard с исходными лицензиями.
- `test/` — сетевые состояния, гонки поиска, личные данные и основной сценарий интерфейса.
- `audit/` — предыдущий аудит словаря; `qa/` — контрольные запросы и результаты приёмки.

Сырая DSL-разметка не попадает в виджеты; исполняемого HTML и генератора морфологии на Dart нет. Backend выдаёт готовые формы и обоснованные границы частей. Предположительные смысловые связи показаны отдельно, по умолчанию в свёрнутом блоке.

## Серверная часть

Реализация нового API находится в соседнем `typikon-web`, публичное чтение этимологий и экспорт семантических справочников — в `interlex`. Порядок подготовки данных и активации описан в `typikon-web/docs/cs-dictionary-v1.md`. Исходные лексемы MongoDB этим приложением не меняются. Отдельная версионированная SQLite содержит пользовательское представление; редакторские решения хранятся отдельно от повторяемого обогащения.

Архив Chu-Rus, базы, дампы, `import/`, `integration/`, секреты, подписи и сборки исключены из Git. Словарная база не включается в APK. `pubspec.lock` отслеживается для воспроизводимой сборки.
