# Приёмка Android 0.1.6+7

Тестовый APK: `build/acceptance/lexicon-cs-0.1.6.apk`. «Лексикон ЦС», `info.typikon.cs`, постоянная подпись выпуска. Установка поверх предыдущих тестовых версий с этой подписью, включая 0.1.5+6. Используется действующий публичный API schema=2.

1. В «О проекте» проверить номер 0.1.6. Найти «благодарити», открыть карточку слова → «Морфемы» → формант «ти».
2. В шапке морфемы проверить название, тип, значение «Показатель инфинитива», статус и статистику. По умолчанию открыта вкладка «Слова».
3. Перейти на следующую страницу слов. Переключить «Слова» → «Состав и этимология» → «Слова»: номер страницы и состав списка сохраняются. Открыть слово и вернуться назад в карточку морфемы.
4. Во вкладке «Состав и этимология» для «ти» проверить исторические компоненты «т» и «и»: по одному прямоугольнику на компонент, в одной горизонтально прокручиваемой строке на белой карточке. Выбрать «и» и прочитать пояснение: оно не объявляется отдельным окончанием современного инфинитива.
5. Прокрутить к историческому описанию, раскрыть «Источники». Проверить сохранение названия А. И. Горшкова и локатора §143, с.106. Год издания не показывается как датировка морфемы.
6. Для карточки «ост / ости» проверить переключатель варианта: модель состава относится к «ости» и не переносится автоматически на «ост». Общие старые описания отдельно отмечены как не привязанные к выбранному варианту.
7. Для морфемы без заданного состава/истории проверить явное сообщение об отсутствии описания. Оно не означает, что морфема исторически простая. Слова без назначенного разбора по-прежнему показывают «Морфемный разбор этого слова пока не задан».
8. Повторить приёмку в тёмной теме и с увеличенным системным шрифтом. Проверить контраст прямоугольников, горизонтальную прокрутку состава, доступность вкладок, вертикальную прокрутку пояснений и отсутствие серых экранов при повторном раскрытии источников.

В текущей публикации 16 моделей состава и 44 исторических описания. Явно заданных цепочек с узлами и связями нет: вместо выдуманных стрелок показаны описания с источниками. Отображение заданных цепочек, совместных входов и статусов проверено автоматическими тестовыми данными; они не включаются в исследовательскую базу.

Клиент запрашивает `schema=2` и не использует старые `structure/history`. Старое серверное представление помечено deprecated. Написания, ударения, варианты и прежняя сегментация окончаний сохранены.

Автоматические проверки, версия, подпись и контрольная сумма: `qa/test-build-0.1.6.json`. Проверка на физическом устройстве выполняется при приёмке. APK хранится локально; публикация в магазине и каталоге обновлений не выполняется.
