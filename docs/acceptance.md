# Приёмка версии 0.1.0

Это реализация для закрытой приёмки, а не объявление готовности к магазину. Серверные изменения подготовлены в typikon-web и interlex; новая публикация создаётся отдельным файлом без изменения исходной MongoDB и Chu-Rus.

## Выполнено

- Flutter: статический анализ без замечаний; девять тестов: тайм-аут, отсутствие сети, независимый отказ interlex, HTTP 429, запоздавших ответов, смены направления, очистки поиска, сохранения избранного/100 последних статей/настроек, ошибки чтения и явной отправки сообщения. Сквозной widget-тест открывает статью и источник, сохраняет слово и открывает настройки при масштабе текста 1,8.
- typikon-web: общий набор — 1 493 успешных теста, два существующих пропуска, ошибок нет. Дополнительно проверены безопасный DSL, разделение библейских ссылок и нумерации значений, адресуемые фрагменты, омонимы, короткие слова, обратный поиск, сегменты, местоимения и сохранение редакторских решений при повторном обогащении.
- interlex: две проверки публичного чтения proto-статьи; gate TypeScript не обнаружил новых ошибок относительно имеющегося baseline. В проекте остаются ранее существовавшие ошибки типов.
- Реальные данные: 480 автоматических контрольных запросов — 360 церковнославянских лемм/выписанных форм из старого снимка и 120 русских эквивалентов источников. Это проверка нахождения, а не замена редакторской проверки смысла каждого перевода.
- Перекрёстные ссылки DSL выделены отдельно от собственных объяснений слова и исключены из переводного и семантического индексов.
- Полный обход форм и связей: выделенные части восстанавливают отображаемую форму; ссылки ведут на существующие адресуемые значения/фрагменты.
- HTTP-проверка на изолированном Mongo: реальные поиск/статья/источник, публичный доступ и CORS, неверные ID/направления, 404, валидация/размер сообщения, запись явно отправленного тестового сообщения, 429 с Retry-After, независимая загрузка interlex.
- Android APK собирается. Flutter Web использован только как временный стенд для визуальной проверки тех же экранов с реальными API.

## До публичного выпуска

1. Активировать новые API и версионированную публикацию на стенде; проверить выбранные URL с мобильного устройства. Затем отдельно выполнить серверную выкладку с предыдущим файлом для отката.
2. Измерить p95 HTTP-поиска на стенде под нагрузкой. Локальные замеры SQLite не доказывают серверный SLA 500 мс.
3. Провести редакторскую приёмку контрольных запросов, особенно титл, вариантов, омонимов и русских многозначных переводов. Машинные связи остаются предположениями.
4. Проверить реальные Android/iOS-устройства, длительные статьи, надстрочные знаки, таблицы, VoiceOver/TalkBack и переключение сети. Здесь нет подключённых мобильных устройств.
5. Собрать iOS на машине с Xcode: в этой среде установлены только Command Line Tools, поэтому сборка iOS не выполнена.
6. Задать магазинную Android-подпись, оформить магазинные материалы и политику обработки добровольно отправленных сообщений. Подготовленный APK подписан отладочным ключом и не публикуется в каталог обновлений Уставных чтений.

## Содержательные ограничения

Неизвестная схема означает отсутствие подготовленной парадигмы. Возраст источника не превращается в помету архаичности. Неидентифицированный источник обозначается явно. Этимологическая связь означает наличие проверенного свидетельства в proto-статье; сама по себе она не утверждает прямое наследование. Автоматические этимологические кандидаты не публикуются. Полный исторический корпус не смешивается с частотами Chu-Rus.

Контроль прежних ID и локальных полей: пропусков/изменений нет. Исходный отпечаток `4e644d50b2ca6c1be6caa31d0695cc2ca556c30ed52df883bb54d885fe41745c` сохранён. Локальный p95 SQL-поиска по контрольному набору — около 7,45 мс; это не результат нагрузочной проверки сервера.

Приватный APK: `build/acceptance/cs-dictionary-0.1.0.apk`. Версия 0.1.0+1, подпись отладочная. Его стандартным серверным адресам нужна активация нового API; до этого для проверки следует собирать приложение с адресами стенда. Публичной выкладки в рамках этой реализации не выполнялось.
