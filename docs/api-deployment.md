## Проверки

- 480/480 публичных контрольных запросов обоих направлений, одна ожидаемая версия данных.
- p95 публичного HTTP-поиска 196 мс, медиана 111 мс: один постоянный HTTP-клиент, до 1,82 запроса/с; измерение включает сеть клиента.
- 30 проверок тем же Dart-репозиторием, который использует APK: формы, источники, короткие слова, титла, обратный поиск, энклитики, подтверждённая смысловая связь и этимология.
- Все восемь публичных proto-статей совпадают с проверенными редакциями по SHA-256.
- Публичное чтение, CORS/OPTIONS, ответы 400/404 и идентичность запущенных релизов.
- При ограниченном всплеске OPTIONS: 30 ответов 204 и 10 ответов 429; отказ содержит JSON, Retry-After, CORS и no-store. Собственный лимит nginx для `/api/v2/cs/` — 10 запросов/с с burst 20; остальные разделы сохраняют прежнюю политику. Лимиты приложения 300 поисков/мин, 600 деталей/мин и 5 сообщений/час остаются действующими.
- `PRAGMA quick_check` и SHA-256 публикации; проверка нативного MongoDB-архива и резервной SQLite interlex.

Машинный отчёт: `qa/deployment-result.json`. Повторить проверку клиента: `dart run tool/check_live_dictionary.dart` после `flutter pub get`. Редакторская приёмка, многопользовательская нагрузка, реальные Android/iOS-устройства и магазинная подпись остаются отдельными этапами.
