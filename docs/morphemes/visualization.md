# Морфемная схема в приложении

Схема использует назначенный API-разбор. Каждой записи `parts` соответствует один цветной прямоугольник с целой морфемой из `surface`; пустая морфема обозначается `∅`. Число прямоугольников равно числу частей разбора, а не числу букв слова.

Прямоугольники расположены в одной строке без переноса. Если схема шире экрана, доступна горизонтальная прокрутка. Длина блока зависит от текста; фиксированной ширины буквенных клеток нет.

Вся схема размещается в белой карточке с внутренними отступами 16 px. Цвет фона и отсутствие цветного тонирования заданы явно, чтобы чёрные корни оставались видимыми в тёмной теме.

Цвета типов морфем сохранены. Общие буквы, указанные API и присутствующие в написании морфемы, выделяются штриховкой внутри блока. Схема показывает составляющие морфемы, а не повторяет непрерывное написание слова: например, обе морфемы на стыке могут содержать одну общую `с`. Написание слова остаётся в карточке слова, а состав морфем не восстанавливается клиентом по догадке.

Нажатие на прямоугольник выделяет соответствующую морфему в именованном списке. Переход в карточку значимой морфемы сохраняется через список. При отсутствии назначенного разбора отображается явное сообщение; ошибка API отличается от отсутствия разбора.

Регрессионные проверки: число блоков, одна строка, горизонтальная прокрутка на узком экране, белая карточка в тёмной теме, крупный текст, сохранение ударений и выбор морфемы нажатием на блок.
