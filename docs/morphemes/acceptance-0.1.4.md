# Приёмка «Морфем»: Android 0.1.4+5

APK: `build/acceptance/lexicon-cs-0.1.4.apk`.
Приложение: «Лексикон ЦС», `info.typikon.cs`.
Сборка release с постоянной подписью; устанавливается поверх 0.1.3 с той же подписью.
Данные загружаются через `https://www.typikon.info/api/v2/cs/`.

## Сценарии на устройстве

1. Открыть карточку слова «богъ» и вкладку «Морфемы». Проверить квадраты с буквами и именованный список; надстрочные знаки должны оставаться при своей букве. Нулевые морфемы должны быть в списке, не добавляя букв в схему.
2. В карточке «помощь» проверить двухцветную штриховку общей буквы «щ». Открыть значимую морфему из списка: должны загрузиться её описание, доступные связи, статистика и связанные слова. Проверить переход в связанную карточку и возврат.
3. В морфеме с числом связанных слов больше размера страницы раскрыть следующую страницу. Проверить отсутствие повторов и соответствие общего числа слов статистике.
4. Открыть «душа», «благодареніе», «печаль», «словество». Переключить доступные разборы: варианты написания и ударения сохраняются. Для «слове́ство» общая «с» отображается один раз с зелёно-синей штриховкой. Историческая атрибуция спорных вариантов остаётся явно неустановленной.
5. Открыть слово без назначенного разбора. Во вкладке должно быть «Морфемный разбор этого слова пока не задан.», без придуманной схемы. Отказ сети/API должен отображаться как ошибка с повтором, а не как отсутствие разбора.
6. Повторить проверку длинного слова и карточки морфемы при увеличенном системном размере текста. Проверить перенос квадратов и читаемость ударений.
