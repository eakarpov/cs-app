# Карточка морфемы: проект экрана

Реализовано 11 ноября 2026 года. API schema=2 опубликован, экран подключён к нему. Исходный интерактивный эскиз и пример цепочки — проектные материалы; действующая база не получает связей из этого примера. Пример «ти» взят из действующего API: 361 лексема, 362 формы, один алломорф. Статистика относится к морфемной публикации `aa52ec1e650bbf82b109b5052337cd2d0c889edd6bcbbf99c4a7eb40dfcc346a`.

## Общая шапка

Название с сохранением исходных букв и ударений; тип морфемы; короткое значение; понятный статус разбора. Для значения `INF` используется явно заданная подпись «Показатель инфинитива», а не вывод по внешнему виду морфемы. Статистика: слова, формы, варианты. Числа относятся только к прямым вхождениям текущей морфемы; исторические родственники не попадают в них автоматически.

Две вкладки: **«Слова»** и **«Состав и этимология»**. При обычном открытии первая вкладка — «Слова»; при переходе к историческому компоненту можно открыть вторую. При переключении сохраняются страница списка, раскрытые источники и позиция каждой вкладки. В иллюстративном эскизе изначально открыта вторая вкладка, чтобы показать новую часть экрана.

## Слова

Постраничный список, который уже существует: лемма, значение, переход на карточку слова. Кнопки Назад / номер страницы / Далее; загружается одна страница. Курсоры и общий итог остаются привязанными к версии базы. Статистика не дублируется отдельными карточками над списком. В эскизе показано только превью трёх настоящих записей; в приложении сохраняется обычная серверная пагинация по 20.

## Состав и этимология

1. **Внутренний состав.** При нескольких алломорфах пользователь выбирает конкретный вариант; модель явно указывает, к каким алломорфам относится. Нельзя переносить состав одного варианта на остальные. Уровень «Письменный состав» / «Исторический состав» виден всегда. При нескольких объяснениях показываются отдельные именованные модели со своими статусами.
2. **Схема состава.** Один прямоугольник на компонент, без переноса строки, с горизонтальной прокруткой внутри белой карточки. Цвета совпадают со схемой разбора слова, когда тип компонента явно указан. Если тип не установлен, прямоугольник нейтральный; родительский тип не копируется детям автоматически. В эскизе оба исторических компонента нейтральные. Присоединение, слияние и неустановленное соответствие различаются текстом, а не одним знаком «+» для всех случаев.
3. **Выбранный компонент.** Под схемой — исходное написание, реконструкция, функция, пояснение, статус и источники. Переход в карточку появляется только при настоящем `morphemeId`; исторический компонент не обязан быть самостоятельной морфемой нашей базы. Разрезы в разборе слова не изменяются при раскрытии исторического состава.
4. **Происхождение.** На телефоне — вертикальная цепочка от более раннего состояния к текущему. У каждого узла: форма или описание состояния, значение, язык, при наличии извод/диалект и период. Реконструкции явно отличаются от засвидетельствованных форм. В эскизе имя на *-ti- — описание реконструируемой основы, а не восстановленная полная словоформа.
5. **Связь между этапами.** Подписана: происхождение, наследование, заимствование, образование, переразложение и т. п. По нажатию раскрываются пояснение, статус утверждения и источники с локаторами. Сплошная линия — редакционно подтверждённая связь; пунктир — предложенная/спорная с явной подписью. Сопоставление родственных форм отображается отдельной ненаправленной связью и не становится предком автоматически.
6. **Разветвления.** Совместные исторические компоненты объединяются одной связью с несколькими входами. Конкурирующие объяснения показываются отдельными цепочками с названиями; они не объединяются в одну доказанную историю. Сначала видны ближайшие этапы, более ранние раскрываются кнопкой «Ранее». Полноэкранный граф не нужен для основной мобильной версии.
7. **Источники и варианты.** Библиографические записи и локаторы доступны у каждого утверждения; список источников снизу служит дополнительным входом. Этимологическая статья interlex открывается существующим просмотрщиком с проверкой ожидаемой редакции. Алломорфы показываются отдельным сворачиваемым списком.

Титла, ударения, реконструкционные звёздочки и исходные буквы не нормализуются для отображения. Год издания словаря не становится временем существования формы. Извод и диалект не выводятся по ударению. Отсутствующие сведения подписываются «Не указан»; для периодов — «Датировка не установлена».

## Пустые и ошибочные состояния

- Нет состава: «Внутренний состав пока не описан». Это не утверждение, что морфема простая.
- Есть только текстовое описание: текст со статусом и источником, без искусственного дробления и стрелок.
- Нет истории: «Этимологические связи пока не описаны».
- Есть заметки, но нет структурированной цепочки: «Историческое описание», обычный текст и ссылки. Порядок заметок не изображается как ход развития.
- Неизвестна часть границы: отображается неразмеченное целое или явно заданный неустановленный компонент. Приложение не выделяет границы само.
- Ошибка списка слов не скрывает шапку и этимологию. Ошибка отдельной статьи источника не удаляет доступную цепочку.
- Версия/схема публикации не подходит: предложить заново открыть морфему из карточки слова, не смешивать данные разных публикаций.

## Приёмка реализации

Две вкладки работают на светлой/тёмной теме и при увеличении шрифта. Белая карточка не меняет контраст исторических компонентов. Состав не переносится на несколько строк; текстовые пояснения переносятся. На ширине 320 dp нет переполнения вне схемы. Поддержаны гипотезы, альтернативные цепочки, слияние двух компонентов и отсутствие истории. Источники привязаны к конкретной связи. Известные варианты «ти», «ост/ости», «а/я/ва» не получают общей структуры без указания области действия. Назад возвращает на прежнюю страницу списка. Временный legacy-адаптер имеет срок удаления по проекту API.

API и миграция: [morpheme-graph-api.md](morpheme-graph-api.md). Формальное описание запроса и ответов: [contracts/morpheme-card.openapi.json](contracts/morpheme-card.openapi.json).

## Итог реализации

Серверный код: `typikon-web` master, `0ba4537`. Новая морфемная публикация: `6734f4aefaa287399a9ad7d09fece448387c8b248873d2a4c69f0957f515e15a`. В ней 208 карточек, 16 моделей состава и 44 сохранённых исторических описания. Явно заданных цепочек в исходной базе нет: соответствующие массивы пусты. Экран умеет показывать заданные цепочки, совместные входы и сопоставления; это проверено тестовыми данными, которые не публикуются как исследовательские выводы. Слияния без заданного буквенного соответствия остаются unmapped. Исходные слова, ударения, варианты, статистика и привязки сохранены.

Детали публикации и проверок: `qa/morpheme-schema2-deployment-result.json`.
