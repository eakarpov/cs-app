# М2-03–06: словарь с корпусным индексом

18 ноября 2026. Мобильная реализация и автоматическая приёмка второго этапа.
Серверная основа — [М2-02 / Unicode 17](m2-02-unicode17-publication.md).
Очная проверка остаётся владельцу; публичный выпуск этим документом не разрешается.

## Результат

Из статьи schema=2 открываются **«Употребления»** с точной версией словаря.
В этом списке только принятые адресные связи. Отдельная кнопка ищет выбранное
написание в пилоте: это другой канал, который не подтверждает лексему или разбор.
В карточках видны контекст с подсветкой, материал, тип совпадения и основание
принятой связи. Пустой список не означает отсутствие слова во всех текстах.

Нижнее меню: **Словарь / Тексты / Связи / Энциклопедия**. Словарь остаётся стартовым.
«Тексты» содержит пять материалов, поиск одного слова/фразы и открытие постоянной
либо старой портальной ссылки. Состояния разделов сохраняются при переключении.

Чтение закрепляет адрес, sourceRevision/passportRevision и согласованный профиль.
Из найденного места сначала открывается проверенное окно, затем можно читать
материал целиком, переходить вперёд/назад по фрагментам. Паспорт и словарь
открываются поверх чтения: возврат сохраняет позицию, профиль, страницу и выделение.
Исходная графика и нормализованный Unicode выбираются явно. Raw остаётся доступен
отдельно; нераспознанные знаки не удаляются. Слово можно нажать в тексте или выбрать
через доступный для экранного диктора список «Выбрать слово».

Паспорт показывает неизвестность переводчика/родного канона, предположительное
авторство, основания, источники и альтернативы. Техническая дата записи не
превращается в дату создания. Публичное чтение не означает свободную лицензию.

## Контракты и переиспользование

- Отдельные `CorpusSession`, `CorpusPage`, `CorpusHit`, `CorpusProjection`,
  `SourceAddress` и `ReaderRepository`; существующий `ReaderReadPacket` сохранён.
- I/C/D/P сверяются при каждом ответе выдачи; продолжение закрепляет I и opaque
  cursor. Каталог сверяет C. Чтение сверяет адрес, профиль, тела, токены, raw/view
  UTF-16, карту и диапазоны. Смещения не переносятся на изменённый текст.
- Flutter не реализует нормализацию/раскрытие титл/Unicode-сегментацию: получает
  ключи, токены и карты сервера. Для подсветки используются surfaceRanges того же
  tokenId, а не поиск похожей строки. Проверяются также границы суррогатных пар.
- Source/unicode r2 согласуются через capabilities; letterfold не предлагается
  индексом и не включён в мобильный выбор. Новые несовместимые профили не выбираются
  молча вместо открытой публикации.
- **Уточнение М2-01 для lookup:** старый reader `/lookup` не закрепляет D.
  Мобильный переход использует уже опубликованный `/api/v2/cs/search?schema=2`
  с точным D и серверным lookupKey из проверенного read-пакета. Это переиспользует
  М1, не требует выкладки сервера и не смешивает версии. Prefix-результаты не
  выдаются за разбор полного токена. Все точные результаты показаны кандидатами,
  пользователь выбирает статью; автоматической привязки к лексеме нет. Старый
  незакреплённый lookup сохраняется для прежних клиентов; его использование
  новым мобильным маршрутом deprecated до поддержки D. Формат старого API не меняется.
- Словарные статьи, источники, избранное, история, формы и морфемы переиспользуются.
  Функция корпуса не требует нового личного хранилища, аккаунта или API-ключа.

## Сеть и смена версии

Поиск/read/resolve не кешируются для офлайна. В памяти ограниченно хранятся только
ETag-тела метаданных, каждый доступ повторно проверяется сервером. 304 без тела
допускает один безусловный запрос. 404/409/410 не подменяются сохранённым текстом.
Сеть отсутствует — показана ошибка и ручной повтор; словарь остаётся работоспособным.
429 учитывает Retry-After, кнопка ждёт, автоматических циклов повторов нет.
Запоздалый ответ старого запроса/профиля и ответ после закрытия экрана игнорируются.
При конфликте продолжения прежние snippets убираются, новый поиск требует действия.

409/410 дают отдельный выбор текущей версии. Несовместимый D в статье не
подменяется версией индекса: пользователь может отдельно открыть текущую статью
или поиск написания. Прежний экран остаётся в стеке возврата.

## Адреса и Android

Копируется тот же HTTPS `/sources/id/...` с ревизиями и селектором, который
понимает портал. Можно вставить его в «Тексты»; старый `/chants/132` разрешается
сервером, numeric ID не интерпретируется устройством.

Android содержит intent filters для HTTPS `/sources/` и
`cslexicon://reader?url=<encoded HTTPS URL>`. Flutter открывает тот же reader
из входящего маршрута. Автоматическое владение HTTPS-доменом (assetlinks),
выбор системного обработчика и холодный/тёплый запуск на устройстве остаются
отдельной очной проверкой: verified App Links этим шагом не объявляются готовыми.
iOS association files/entitlements не добавлялись.

## Приёмка и ограничения

Результаты: [автоматическая приёмка](../qa/mobile/m2-mobile-acceptance.json),
[публичный HTTPS через Dart](../qa/mobile/m2-mobile-live.json).
Тесты проверяют маршрут каталог → чтение → паспорт → кандидаты → статья → возврат,
неоднозначность, личные данные, недоступный корпус, поздние ответы, квоты, 304,
смену I/C/D/P, чужие токены/карты и UTF-16/PUA. Это проверки утверждений в тестах,
без запуска APK и самостоятельной визуальной приёмки.

Пять материалов прочитаны через публичный HTTPS, включая продолжения канона и
акафиста. Число навигационных единиц — 68, физических размещений — 67.
По «Христос» сервер возвращает 14 совпадений написания; принятых связей этой
лексемы — 3. P01/P04 разделяют одно размещение; три разных токена в нём остаются
тремя употреблениями. Неизвестные сведения паспортов не изменялись.

Текстовые тела/SQLite не включаются в APK. Хранения полного корпуса офлайн нет;
после перезапуска позиция чтения не восстанавливается автоматически. Сноски,
лица/темы, массовая разметка и редакторский кабинет не входят в эту поставку.
Для слова показана первая ограниченная страница кандидатов; наличие продолжения
обозначается явно. Покрытие принятых связей остаётся частичным: четыре решения
Codex не равнозначны полной научной или морфологической выверке.

М2-03–05 реализованы. М2-06 закрыт автоматически в этих границах; полное закрытие
ожидает проверки владельцем: обе темы, крупный шрифт, PUA/титла, TalkBack,
возврат и реальные Android-ссылки. М1-09/10 также сохраняют свою очную приёмку.
APK подготовлен локально; публикация и update endpoints не меняются.

Очные сценарии:

1. Найти «Христос» → статья → «Употребления»: три принятых места, отдельно поиск
   написания с 14 совпадениями. Открыть место, паспорт, слово и вернуться назад.
2. «Тексты» → канон/акафист: страницы вперёд и назад; переключение графики.
3. Глава Маргарита: PUA/титла, исходная графика, неизвестный переводчик и
   предположительное авторство. Ирмос: неизвестный родной канон.
4. Отключить сеть, повторить чтение и вернуть сеть; проверить сохранность запроса,
   статьи и избранного. Тёмная тема, увеличенный шрифт, TalkBack.
5. Постоянная/старая ссылка через поле «Тексты», затем внешний Android intent
   (холодное и уже запущенное приложение). Автовыбор HTTPS не гарантирован без
   отдельной проверки системных настроек/assetlinks.
