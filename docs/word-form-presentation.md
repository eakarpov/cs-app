# Шапка слова и основной вид форм

Характеристики в шапке поступают из `properties` статьи API. Грамматика найденной формы поступает отдельно из результата поиска: сервер объединяет анализы исходных форм и ячеек парадигм. Эти два уровня не следует выводить одной длинной строкой.

В шапке остаются общие свойства лексемы без точных повторов. Характеристики отдельной найденной словоформы раскрываются по нажатию. `plen`, `sg` и прочие признаки отдельных форм не показываются среди общих свойств слова.

Вкладка «Формы» по умолчанию показывает таблицу. Для именных частей речи строки соответствуют падежам, столбцы — единственному, множественному и двойственному числу. Если есть родовые различия, они разделены на таблицы. Для глаголов используются лица и числа, раздельно по времени/наклонению. Первая основная парадигма раскрыта; для прилагательных при наличии выбираются полные формы. Остальные группы можно раскрыть самостоятельно. На узком экране таблица прокручивается горизонтально.

Для осей используются только структурные ID ячеек API. Совпадающие падежи/лица в объединённых ячейках распределяются по соответствующим клеткам; частная ячейка имеет приоритет перед общей. Неизвестные ID сохраняются отдельными подписанными строками. Отсутствующие формы не достраиваются клиентом.

В основной клетке показывается первое переданное API написание без титла и выносных букв. Это представитель для показа, а не новая редакторская норма. Точные дубли написаний удаляются. Дополнительные написания и варианты доступны через кнопку «Иные написания»; заметка в диалоге объясняет их статус. Происхождение формы и отличие расчётной формы от выписанной доступны в подсказке.

Переключатель «Подробно» сохраняет просмотр по исходным грамматическим подписям ячеек. Написания под титлом исключены из склонения в обоих режимах. Сокращённый вариант начальной формы выводится под полным заголовочным написанием. Для этого используются только явно назначенные API начальные ячейки или подписанные именительные формы; родительный и другие косвенные падежи не подменяют заголовок. Если полного написания нет в данных, приложение не разворачивает сокращение по догадке.

Регрессионные проверки охватывают повторы характеристик, сокращения в заголовке, фильтрацию титл/выносных букв, альтернативные написания, падежные таблицы, родовые различия и объединённые лица глаголов, переключение подробного вида и возврат во вкладку на реальных статьях «земля» и «ава».
