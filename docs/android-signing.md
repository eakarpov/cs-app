# Постоянная Android-подпись «Лексикона ЦС»

Ключ выпуска создан 9 ноября 2026 года до первой магазинной публикации.
Он хранится вне проекта рядом с ключами других приложений:

- `~/.config/lexicon-cs/release-keystore.jks` — постоянный JKS, RSA 4096.
- `~/.config/lexicon-cs/signing.properties` — путь, alias и пароли.
- `~/.config/lexicon-cs/release-certificate.der` — открытый сертификат.

Alias: `lexicon-cs-release`. Срок сертификата — 10 000 дней.
SHA-256 сертификата:
`efbd5403c1bf73c63e8feac9f95b71b2231c96e7d39c8f2be6a153089a8398f8`.

Каталог имеет права 0700, закрытый ключ и настройки — 0600. Пароли не
печатаются в журнал сборки и не хранятся в репозитории. Для переноса сборки
нужно восстановить этот каталог и при необходимости поправить `storeFile`
в закрытом файле настроек; создавать новый ключ для обновлений нельзя.
Сохранение резервной копии должно включать ключ и файл настроек с паролями.

Gradle по умолчанию читает этот постоянный файл настроек. В CI можно задать
`CS_ANDROID_SIGNING_PROPERTIES` с путём к защищённой копии того же файла.
Обычная команда выпуска:

```sh
flutter build apk --release
```

Сборка не генерирует ключи и не изменяет их. До выполнения release-задач
проверяются настройки, наличие ключа и точный отпечаток сертификата.
При отсутствии настроек или другом сертификате сборка завершается ошибкой;
автоматической подмены на debug-подпись нет.

Отладочные сборки по-прежнему используют обычную Android debug-подпись.
APK с постоянным ключом нельзя установить поверх прежних debug-сборок:
это смена подписи до первого магазинного выпуска. Сам сборщик ничего не
удаляет с устройств.
